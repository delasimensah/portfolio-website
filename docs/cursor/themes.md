# Themes

Cursor supports **light and dark themes** and inherits **VS Code theming**: use any VS Code theme, create custom themes, and install theme extensions from the marketplace.

**Use this doc when:** You want to switch theme, use a VS Code theme in Cursor, or create a custom theme.

**For theme extensions and authoring:** [VS Code – Color Themes](https://code.visualstudio.com/docs/getstarted/themes).

---

## Changing theme

1. **Command Palette** (⌘⇧P / Ctrl+Shift+P).
2. Type **theme** and choose **Preferences: Color Theme**.
3. Pick a theme from the list.

---

## FAQ

- **Use VS Code themes in Cursor?** Yes. Cursor uses VS Code’s theming; themes that work in VS Code work in Cursor. Install from the Extensions marketplace if needed.
- **Create a custom theme?** Same as in VS Code. Use **Developer: Generate Color Theme From Current Settings** to start from your current colors, or follow the [VS Code theme authoring guide](https://code.visualstudio.com/api/extension-guides/color-theme) to build one from scratch.
