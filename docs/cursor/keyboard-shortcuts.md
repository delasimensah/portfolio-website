# Keyboard Shortcuts

Quick reference for Cursor keyboard shortcuts. You can **remap** any shortcut, including Cursor-specific ones, in **Keyboard Shortcuts** (⌘/Ctrl + **K** then ⌘/Ctrl + **S**, or Command Palette → “Keyboard Shortcuts”).

**Use this doc when:** You need a shortcut for chat, inline edit, Tab, terminal, or general Cursor actions.

**For full list and customization:** Open **Keyboard Shortcuts** in Cursor, or see [VS Code Key Bindings](https://code.visualstudio.com/docs/getstarted/keybindings) as the baseline for Cursor’s keybindings.

---

## General

| Shortcut (Mac / Win) | Action |
|----------------------|--------|
| **⌘ I** / **Ctrl I** | Toggle Side panel (unless bound to mode) |
| **⌘ L** / **Ctrl L** | Toggle Side panel (unless bound to mode) |
| **⌘ E** / **Ctrl E** | Toggle Agent layout |
| **⌘ .** / **Ctrl .** | Mode menu |
| **⌘ /** / **Ctrl /** | Cycle between AI models |
| **⌘ ⇧ J** / **Ctrl ⇧ J** | Cursor settings |
| **⌘ ⇧ Space** / **Ctrl ⇧ Space** | Toggle Voice mode |
| **⌘ ,** / **Ctrl ,** | General settings |
| **⌘ ⇧ P** / **Ctrl ⇧ P** | Command palette |

## Chat

| Shortcut (Mac / Win) | Action |
|----------------------|--------|
| **Return** / **Enter** | Nudge (default) |
| **Ctrl Return** / **Ctrl Enter** | Queue message |
| **⌘ Return** / **Ctrl Enter** (when typing) | Force send message |
| **⌘ ⇧ Backspace** / **Ctrl ⇧ Backspace** | Cancel generation |
| **⌘ ⇧ L** / **Ctrl ⇧ L** (code selected) | Add selected code as context |
| **⌘ V** / **Ctrl V** (code/log in clipboard) | Add clipboard as context |
| **⌘ ⇧ V** / **Ctrl ⇧ V** (code/log in clipboard) | Add clipboard to input box |
| **⌘ Return** / **Ctrl Return** (suggested changes) | Accept all changes |
| **⌘ Backspace** / **Ctrl Backspace** | Reject all changes |
| **Tab** | Cycle to next message |
| **⇧ Tab** | Rotate between Agent modes |
| **⌘ ⌥ /** / **Ctrl Alt /** | Model toggle |
| **⌘ N** / **Ctrl N** or **⌘ R** / **Ctrl R** | New chat |
| **⌘ T** / **Ctrl T** | New chat tab |
| **⌘ [** / **Ctrl [** | Previous chat |
| **⌘ ]** / **Ctrl ]** | Next chat |
| **⌘ W** / **Ctrl W** | Close chat |
| **Escape** | Unfocus field |

## Code selection & context

| Shortcut (Mac / Win) | Action |
|----------------------|--------|
| **@** | [@-mentions](./at-mentions.md) / shortcut commands |

| **⌘ ⇧ K** / **Ctrl ⇧ K** | Add selection to Edit |
| **⌘ L** / **Ctrl L** | Add selection to new chat |
| **⌘ M** / **Ctrl M** | Toggle file reading strategies |

| Select → **⌘ C** / **Ctrl C** → **⌘ ⇧ V** / **Ctrl ⇧ V** | Add copied code as text context |
