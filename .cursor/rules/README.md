# Cursor rules (project template)

Rules in this folder guide the agent for this monorepo template. Use them across projects spun from this template.

## Top-level rules

- **code-organization-and-style.mdc** — Repo structure, components, services, hooks, imports, app layout. Always apply.
- **system-design-planning.mdc** — When to use system design; read docs/system-design and produce a plan. Always apply.
- **official-documentation.mdc** — Prefer official docs, use @Docs, scope by path. Applies under apps/ and packages/.
- **base-developer.mdc** — Developer preferences: follow user examples first, code style, project org, content preservation. Always apply.

## Entry point

**AGENTS.md** (project root) lists the stack and official doc URLs. Rules reference it for the canonical list.
